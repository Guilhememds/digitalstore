# Digital Store — Projeto Full Stack

Repositório contendo as aplicações **Back-end** e **Front-end** desenvolvidas para o projeto de avaliação da **Geração Tech**.

## Estrutura do Repositório

```text
digitalstore/
├── Back/     # API RESTful em Node.js, Express, Sequelize e MySQL
└── Front/    # Aplicação web responsiva em React, PrimeReact e styled-components
Tecnologias Principais
Back-end: Node.js, Express, Sequelize, MySQL, JWT (jsonwebtoken), dotenv

Front-end: React, Vite, PrimeReact, styled-components
```
